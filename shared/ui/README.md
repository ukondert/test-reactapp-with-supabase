# @shared/ui

Plattformuebergreifendes UI-Paket fuer Web (React + Vite) und Mobile (React Native/Expo).

## Enthaltene Komponenten

- `StatusMessage`: Zeigt einen Status-Text mit den Varianten `success`, `error` oder `info`.

## Namenskonvention

- `*.web.jsx` fuer Browser-Implementierungen
- `*.native.jsx` fuer React Native Implementierungen
